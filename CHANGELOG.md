# Changelog

## v0.5.1-preview.1 — 2026-10-26

First public source release of the tested Xiaomi 14 PixelOS integration.

- System Quick Share entry with phone-only automatic start/stop and continuous bidirectional AirDrop sessions.
- Large-file transfer support; tested 128 MiB ZIP, photos and Word content.
- Temporary real country-code permission lease, rollback ledger and boot/uninstall recovery for updated Google components.
- Wi-Fi re-enable race checks and in-place recovery before any driver unload attempt.
- Source, license notices, original-ROM-to-KSU installation guide, update/recovery guide, and offline local assembly tool.
- Closed Google components, Samsung AMSS, author ROM/init_boot and private signing credentials are excluded. Users must provide compatible dependencies themselves.

This is a preview for the exact published profile. Newly self-signed assembly has been checked offline and is not a universal or independently phone-validated build.
